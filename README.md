# To_Do_List_App
A beginner friendly python project demonstrating basic input output operations using input() and output(). Created as part of my journey to learn python programming.

ABOUT THE PROJECT:
-This id beginner level python project created to practice the fundamentals of python programming.
-The project demonstrated how to take input from users and display personalized message using python.

CONCEPT USED:
1.input() - To accept the input from user.
2.print() - To display output.
3.Variables - To store user information.
4.Basic string handling.

HOW TO RUN:
1.Install python on your computer
2.Clone or download this repository
3.Open the project folder in VS code
4.Open the terminal
5.Run the command-python new.py

TOOLS USED:
1.Python 3
2.Visual Studio Code

WHAT I LEARNED:
1.How to take input from user.
2.How to use variables.
3.How to display output using print().
4.How to execute python programs.
